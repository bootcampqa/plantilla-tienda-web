## 🚀 Cómo empezar a usar esta plantilla

Sigue estos sencillos pasos para llevártela a tu cuenta de GitHub y empezar a trabajar en ella:

1. **Inicia sesión** en tu cuenta de [GitHub](https://github.com).
2. Ve al repositorio oficial de la plantilla: [github.com/bootcampqa/plantilla-tienda-web](https://github.com/bootcampqa/plantilla-tienda-web).
3. Haz clic en el botón verde **"Use this template"** (Usar esta plantilla) situado en la parte superior derecha y selecciona **"Create a new repository"**.
4. Escribe un nombre para tu nueva web y haz clic en **"Create repository from template"**.
5. ¡Listo! Ya tienes una copia exacta en tu perfil para empezar a practicar y crear tu propia web.
